# references/

Documents juridiques et administratifs officiels servant de **référence** au projet.

Différent de `data/external/` (qui contient des données opérationnelles gitignored).
Ici, ce sont des textes courts, publics, juridiquement opposables, utiles à versionner avec le code.

## Contenu

- `circulaires/` : circulaires ministérielles applicables (nuances politiques, etc.)
- Ajouter ici tout texte officiel mobilisé par le code ou les skills.

## Convention de nommage

`AAAA-MM-JJ_REFERENCE_objet-court.pdf`

Exemple : `2026-02-02_INTP2602966C_nuances-municipales-2026.pdf`
