# ministere-de-l-info

Application web locale de data-visualisation politique, électorale, économique et territoriale française.

## Stack technique

- **Python 3.12** + `uv` (gestion paquets)
- **Streamlit** (interface web)
- **DuckDB** (base de données analytique)
- **Polars / Pandas / GeoPandas** (manipulation de données)
- **Folium / Plotly** (cartographie et visualisations)
- **Tectonic** (compilation LaTeX pour rapports)
- **Docker** (déploiement local via OrbStack)

## Sources de données

- data.gouv.fr (élections, RNE, EPCI)
- INSEE (Melodi, BDM, Sirene)
- Légifrance via PISTE (textes législatifs)
- geo.api.gouv.fr (référentiel géographique)
